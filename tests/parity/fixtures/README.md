# Chetty Table I references

`chetty_matlab.json` preserves the Table I arrays from the November 23,
2026 review’s MATLAB R2025b run of the authors’ routines. The authors'
inputs and routines are identified in the [source register](../../../spec/0.1.0/sources.md).
It records the historical finite-grid calculation.

`chetty_0_3_9.json` records the corresponding Python/Rust candidate
with methods 0.3.9, core f495a5b and scpc-python 70bcbb5.
Both archives cover the 26 complete-case, standardized continental
bivariate fits in levels and after LBM-GLS. The 0.4.0 verification
separately checks installed host agreement, historical author arithmetic,
and whether changes are attributable to the calibrated covariance endpoint.
